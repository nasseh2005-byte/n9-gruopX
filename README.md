# N9 Group Platform

منصة N9 Group مبنية بـ Next.js وتحتوي على صفحات متعددة، لوحة إدارة بسيطة، ونموذج تواصل فعلي.

## المتطلبات
- Node.js 18+
- npm

## التثبيت والتشغيل المحلي
```bash
npm install
npm run dev
```

## البناء النهائي
```bash
npm run build
npm start
```

## لوحة الإدارة
- المسار: `/admin`
- كلمة المرور الافتراضية: `N9-2026`
- التخزين الحالي: `LocalStorage`

## المميزات
- صفحات متعددة
- تصميم فاخر مع مؤثرات وحركة خفيفة
- صوت تقني عند الضغط على العناصر المحددة
- نموذج تواصل فعلي مع API route
- لوحة إدارة تدعم الإضافة والتعديل والحذف
- شعارات SVG جاهزة للعرض

## النشر على Vercel
1. ارفع المشروع إلى GitHub.
2. افتح Vercel.
3. اختر **New Project** ثم اربط المستودع.
4. استخدم الإعدادات الافتراضية؛ Vercel يكتشف Next.js تلقائيًا.
5. اضغط **Deploy**.

## ملاحظات قبل النشر
- اختبر `npm run build` محليًا.
- عدّل كلمة مرور `/admin` قبل النشر الفعلي.
- استبدل الروابط التجريبية بروابط حقيقية عند توفرها.
- إذا أردت تخزينًا دائمًا حقيقيًا، استبدل `LocalStorage` بقاعدة بيانات.
